# Basil — Portfolio

Personal portfolio built with Vue 3 + Vite. Design ported from [Cleanfolio](https://github.com/rjshkhr/cleanfolio).

## Structure
```
src/
  content.js      # all site content — edit this to update the portfolio
  style.css       # light/dark theme tokens and shared styles
  App.vue
  components/     # one component per section
public/images/    # avatar, favicon, OG image, project screenshots
```

## Development
- `npm install`
- `npm run dev`

## Deployment
- `npm run build && npm run deploy`
